## 2. 逐行解读（可照着讲）

| 阶段 | 输出 | 对应规则 / 得分点 |
|---|---|---|
| 题目 | `PRACTICE REQUEST …` | 客户要：同家族、平衡XLR、续航≥12h 的**可用项**里选最轻的，用项目积分付差价，先说清再确认后改 |
| ① 鉴权 | `locate_member {全名,6位码}` | 规则1：先验证身份（护栏放行） |
| ② 读档案 | `read_member_profile {MB-...}` | 取积分 `CR-AFCE80FF`（余额75）作资金来源 |
| ③ 读预约 | `read_reservation {RS-...}` | 取状态 `awaiting_collection` 与当前资产 `EQ-C2B2059D` |
| ④ 查家族 | `inspect_asset_family {AF-...}` | **证据来源**：所有选项的规格/费用/可用性 |
| ⑤ 算费差 | `compute_amount "53.5 - 39.5"` | 规则3：用工具算精确差价 = 14.00（不瞎编） |
| ⑥ 提案+要确认 | `AGENT: …lightest available qualifying option…EQ-5C143A54…fee $14.00…CR-AFCE80FF…Please confirm` | **规则3/5/8**：说明目标/当前/新项/费差/资金来源，并请求明确确认 |
| ⓻ 证据判断（亮点） | `EQ-3FCB35D6 (330g) would be lighter but is unavailable and cannot be selected` | **得分点**：排除了"更轻但不可用"的项，严格按"可用+约束"取真最优（证据判断 15%） |
| ⑧ 客户确认 | `MEMBER: Yes, I confirm…proceed.` | 平台注入的"新鲜、明确"确认（护栏 `_confirmation_present` 通过） |
| ⑨ 写 | `change_reserved_asset {旧→新, 信用}` | 规则3：确认后才写；参数精确（新项=合规最轻，信用覆盖差价） |
| ⑩ 汇报 | `AGENT: …Selected option…$14.00 additional…CR-AFCE80FF…awaiting_collection_changed` | 规则"沟通"：用核实结果汇报选中项/费差/资金来源/成功 |

> **一句话亮点**：模型没有机械选"最轻的 330g"，而是先过滤"可用 + 平衡XLR + 续航≥12h"，再在合格项里取最轻（365g）——这正是考试"Evidence-based information judgment"与"Apply every constraint"的高分项。

## 3. 本地跑通必须的两个修复（仅本地，不影响考试提交）

> 考试平台自带代理、自带模型、不暴露 reasoning，**不需要这些修复**；它们只影响你在本机用自己 key 跑 `practice_runner.py`。

1. **`reasoning_content` 回传（否则 `HTTP 400`）**：DeepSeek 思考模式多轮对话要求把上一轮 `reasoning_content` 回传。原 `agent._enforce` 剥离了非合同字段导致丢失。修复：`agent.py` 放行时保留、`interview_sdk._normalise_message` 的 content 分支也保留、`practice_runner.py` 的 content 类助手消息也回显。
2. **GBK 打印错误（否则含 `✓` 等字符时 `UnicodeEncodeError`）**：Windows 控制台默认 GBK 打不出 `✓`。运行前设环境变量：`$env:PYTHONIOENCODING="utf-8"`。

## 5. 讲解要点（汇报/讲解用）

1. **这是什么**：无状态事务型客服 Agent；平台反复调 `respond(messages, tools, policy)`，每轮只返回"说一句"或"调一工具"。
2. **为什么难**：每轮只给完整对话、不能存全局变量；考试无外网、模型不可控；政策极严；数据每次随机（必须通用）。
3. **架构三层**：提示词层（政策+8规则+工作流）→ 模型层（平台/本地 LLM）→ 护栏层（确定性校验）。
4. **为什么加护栏**：模型不可控 + 安全纪律占 15% + 越权写重罚；把安全从"指望模型自觉"变为"代码硬保证"。
5. **三道关键护栏**：鉴权门、写前状态门（必须 awaiting_collection、旧资产真实存在）、确认新鲜度门（确认须在最近提案之后，改主意自动失效）。
6. **实测证据**：真实模型跑通，且正确排除"更轻但不可用"项、算对费差、确认后才写、汇报核实结果——覆盖意图/工具参数/计划执行/证据判断/表达/安全六维。
